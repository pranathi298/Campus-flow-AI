# CampusFlow AI

AI-powered Smart Classroom & Laboratory Allocation System for colleges.

## Features
- Admin dashboard
- Classroom and laboratory management
- Timetable view
- AI-based room recommendation
- Floor map
- Student display board
- Reports and utilization metrics

## Tech Stack
HTML5, CSS3, JavaScript

## Live Demo
Enable GitHub Pages for this repository to publish the application.

## Purpose
CampusFlow AI helps colleges reduce classroom conflicts and allocate suitable rooms based on capacity, availability, room type and timetable requirements.
